    このアプリケーションは、Realworld Agent プロジェクトの議事録エージェントのプロトタイプです。

    実装予定の機能:

    • ✅ 動画ファイルのアップロード
    • 🔄 音声抽出と文字起こし (Groq Whisper API)
    • 🖼️ キーフレーム検出
    • 🧠 マルチモーダルLLM (Groq GPT-OSS-120B) による議事録生成
    • 📝 Markdown形式での保存
    • ☁️ Notion/GitHub/Google Drive への自動保存
